About this project

Host v1.0.0

What this build does

Provides a PS4-browser-friendly dashboard, firmware identification, external community host links, and safe compatibility checks on ULTility's static website.

It does not contain a custom WebKit vulnerability, a native userland or kernel exploit, GoldHEN binaries, or an offline jailbreak chain.

Use carefully

Firmware is inferred from the browser user agent, not independently verified. Check Settings → System → System Information on your PS4. Do not install unverified payloads or update firmware without checking compatibility.

The external host runs under its own website and is maintained separately from this project.
